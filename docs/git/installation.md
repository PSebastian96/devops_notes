# Installation

## Linux

On Debian/Ubuntu:

```bash
sudo apt update
sudo apt install git
```

Verify the installation:

```bash
git --version
```

## macOS

Using Homebrew:

```bash
brew install git
```

Verify:

```bash
git --version
```

## Windows

Git can be installed using the official Git installer or through a package manager such as `winget`.

Using `winget`:

```powershell
winget install --id Git.Git
```

Verify:

```powershell
git --version
```

## Verify Git

After installation:

```bash
git --version
```

Example:

```text
git version 2.x.x
```

!!! note
    The exact version depends on your operating system and installation source.
